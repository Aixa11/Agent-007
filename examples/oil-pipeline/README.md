# Oil Pipeline Minimal Example

## Context
This example demonstrates how Secure Architect Agent should approach an existing critical infrastructure repository.

## Input
A user already has:
- a working pipeline,
- a historical deployment flow,
- established naming conventions,
- and operational constraints.

## Expected agent behavior
The agent must:
- analyze the current structure,
- identify security and governance gaps,
- propose minimal improvements,
- preserve compatibility with the current pipeline,
- and validate the result locally.

## Example outcome
Instead of recommending a full redesign, the agent should suggest:
- tighter access boundaries,
- clearer documentation,
- validation scripts,
- and small structural improvements.

## Success criteria
- No destructive rewrite.
- No broken pipeline assumptions.
- Clear reasoning for every proposed change.
- Local validation completed successfully.
